# Parcours francais : dispute-game-tool (recherche offchain des dispute games a blacklister)

Lecture pedagogique du depot base/dispute-game-tool : un script Python d incident qui lit le storage brut d une DisputeGameFactory pour determiner, apres une divergence de client, la liste des dispute games a blacklister.

Sommaire :

Chapitre 1 Presentation de dispute-game-tool. Chapitre 2 Lire le tableau des dispute games via le storage brut. Chapitre 3 Filtrer par block de divergence et produire la liste finale. Chapitre 4 Limites et perimetre de ce parcours.

Ce parcours est une lecture pedagogique du code source et de la documentation du depot, sans installation ni execution du projet.
